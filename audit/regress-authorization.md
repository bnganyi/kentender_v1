## 1. Method

Scope: every authorization finding the tracker lists in Waves 1-4 (whitelisted endpoints, actor-parameter impersonation, Budget service principals, TM2 removal, supplier registry gates, User Permission use, `ignore_permissions`/`allow_guest`, command-only write guard coverage, scope hooks, Award role matrix, Strategy change-set confinement, Requisition handoff consumption). Findings that are purely money/concurrency, audit-trail or SoD-chain content (XC-101..109, 115..120, 129..133, TND/EVL/AWD ordering rules) belong to the other sweeps and are not re-judged here.

Commands and patterns used (all read-only):

```
git log --oneline origin/mvp1/dev..HEAD            # 73 commits (list in section 5)
# every whitelisted function, decorators and frappe.whitelist()(fn) aliases (AST walk, scratchpad wl.py; not committed)

git diff 9c7c9a6d HEAD -U0 | grep "ignore_permissions=True"           # +64 / -93 (re-wrapped, none on an ungated read path)

```

Frappe facts relied on (read, v16): `get_newargs` drops request fields not in `inspect.signature(fn)` (honours `__signature__`), so the Needs `_session_endpoint` wrapper really hides `user`; `flags` is a reserved keyword in `BaseDocument.update` (a posted body cannot set `doc.flags`), so the command-write guard is not spoofable that way; `get_roles("Administrator")` returns every Role.

Current endpoint inventory: 624 whitelisted (no new one since the audit; 44 fewer than 668: TM2, Budget money-moving 6 + the DIA adapter, Needs projections 3, Requisition consumption 1, legacy AUTH-G04 writers 3). Guest endpoints: 5, unchanged set (`bid_submission/api.py:42,48,59`, `bid_opening/api.py:312`, `suppliers/api/smw_public.py:24`). Whitelisted functions with an acting-user parameter: none (only the three `responsibility_api` grantee parameters `user`, which are the allow-listed subject, `kentender_core/tests/test_whitelisted_principal_parameters.py:46-52`).
