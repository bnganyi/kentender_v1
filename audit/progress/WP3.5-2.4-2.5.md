## Follow-ups
1. AUD-XC-132 (owner decision). Unclear: PLN v1_29 §5.5.3.1 defines `required = percentage x eligible value` and RES-IMP-001 says nothing on rounding; the code rounds the required amount half-up to the cent (`readiness.reservation_measure`), so 100.01 at 30% is 30.00 and 30.00 qualifying reads as met at 29.997%. Options: (a) accept half-up (current); (b) round the required amount up; (c) compare exactly (`qualifying >= eligible x percent / 100`, no rounding) and only display at two places. Recommended: (c). Did: nothing; marked Blocked.
2. AUD-XC-118 residuals. (a) The accepted event (`events.accepted_payload`) and the plan hand-off still carry `indicative_quantity` as a JSON float via `flt`, and the content hash is over that form; moving it to a decimal string is the coordinated cutover NDS11-XD-004 names (hash continuity, Planning consumer, REQ). (b) The column is a Frappe Float (decimal(21,9)), so the supported range is 12 integral digits, not the 18 NDS asks for; a wider column needs a migration. (c) ERPNext's UOM has no fractional-scale column, so the only per-unit rule is `must_be_whole_number`; the scale limit is the column's three decimals until CFG publishes a per-unit precision. (d) NDS §4.9 says unit eligibility is rechecked at acceptance; `review_need` does not re-run `NDS_UNIT_INELIGIBLE` or the quantity rule (only submit does). Recommended: do (d) next, (a)-(c) with the owner-document cutover. (e) Requisition Item quantity is still an Int (REQ).
3. AUD-XC-133 residuals. Budget publishes no CurrencyBasis contract and its display statement (`check_plan_affordability`) carries no `currency_precision` (only the decision statement does); Planning therefore takes precision from the captured Financial Basis for the display digest. Many Planning calls still use `money.money_text`/`parse_money` at the default two places, and display helpers print "KES" (`readiness.money`, `plan_read._money`). Recommended: Budget publishes the contract (WP3.x), then Planning threads `precision` and the currency label through its reads.
