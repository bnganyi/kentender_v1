Every STD Administration screen should show, where relevant:

\- Object name

\- Object code or identifier

\- Lifecycle state

\- Validation state

\- Source authority

\- Version number

\- Last modified date

\- Approval/review status

\- Whether the object is editable or locked

\- Primary action

\- Secondary actions

\- Audit or source traceability access

Use clear state labels:

\- Draft

\- Structuring

\- Internal Review

\- Legal Review

\- Procurement Review

\- Approved

\- Active

\- Suspended

\- Superseded

\- Archived

Use clear validation labels:

\- Valid

\- Warning

\- Blocked

\- Not Tested

\- Review Required

Use clear lock labels:

\- Locked Clause

\- Controlled Parameter

\- Configurable Section

\- System Generated

\- Tender-Specific Value

Avoid ambiguous labels such as Submitted, Ready, In Progress, or Done unless the underlying state is shown as well.
