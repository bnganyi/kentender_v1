Screen name:

Version Diff and Supersession

User:

STD Administrator, Legal Reviewer, Procurement Reviewer

Purpose:

Compare two STD versions and manage supersession.

Primary user goals:

\- Compare changes between versions.

\- See clause, parameter, rule, form, and render differences.

\- Understand tender impact.

\- Supersede an active version with an approved new version.

Required sections:

1\. Version comparison selector.

2\. Diff summary cards.

3\. Change category tabs.

4\. Detailed diff table.

5\. Tender impact panel.

6\. Supersession decision panel.

Change categories:

\- Sections

\- Clauses

\- Parameters

\- Rules

\- Forms

\- Requirements

\- Evaluation

\- Render blocks

\- Contract forms

\- Smoke tests

Diff table columns:

\- Object type

\- Object key

\- Change type

\- Old value

\- New value

\- Legal impact

\- Tender impact

\- Review status

\- Actions

Required actions:

\- Compare Versions

\- Open Changed Object

\- Export Diff

\- Mark Reviewed

\- Supersede Active Version

Design constraints:

\- Legal text changes must be highly visible.

\- Supersession must be formal and irreversible except through another approved version.
