Screen name:

Price Schedule Schema

User:

STD Administrator, Commercial/Procurement Designer

Purpose:

Define structured pricing tables required by the STD.

Primary user goals:

\- Configure price schedule structure.

\- Define summary and sub-table relationships.

\- Validate totals, currencies, taxes, recurrent costs, and contract carry-forward.

Required sections:

1\. Price schedule summary.

2\. Schedule/table list.

3\. Price line schema builder.

4\. Calculation rules panel.

5\. Render/contract carry-forward panel.

Required table types:

\- Grand summary

\- Supply and installation cost summary

\- Recurrent cost summary

\- Supply and installation sub-table

\- Recurrent cost sub-table

\- Country of origin table

\- Optional custom schedules by STD type

Required fields:

\- Schedule code

\- Schedule name

\- Pricing basis

\- Currency policy

\- Tax/VAT handling

\- Recurrent cost policy

\- Total formula

\- Required/conditional

\- Evaluation linkage

\- Contract carry-forward

Required actions:

\- Open Schedule

\- Add Line Schema

\- Configure Formula

\- Run Calculation Test

\- Preview Price Form

\- View Evaluation Linkage

Design constraints:

\- Do not call IT price schedules “BoQ.”

\- Make financial evaluation linkage explicit.
