Screen name:

Evaluation Schema

User:

STD Administrator, Evaluation Policy Designer

Purpose:

Configure evaluation stages, criteria, scoring, pass/fail rules, and financial comparison model for an STD version.

Primary user goals:

\- Define evaluation stages.

\- Configure mandatory responsiveness criteria.

\- Configure technical scoring.

\- Configure financial evaluation.

\- Confirm lowest evaluated responsive tender logic.

\- Link evaluation criteria to supplier forms and requirements.

Required sections:

1\. Evaluation overview.

2\. Stage list.

3\. Criteria table.

4\. Scoring/threshold panel.

5\. Financial evaluation panel.

6\. Linkage panel.

7\. Validation warnings.

Required stages:

\- Preliminary responsiveness

\- Eligibility/qualification

\- Technical evaluation

\- Financial evaluation

\- Post-qualification

\- Award recommendation

Criteria table columns:

\- Criterion code

\- Criterion name

\- Stage

\- Type: pass/fail, scored, calculated

\- Max points

\- Pass threshold

\- Source form/requirement

\- Evidence required

\- Rule binding

\- Status

Required actions:

\- Add Criterion

\- Configure Scoring

\- Configure Threshold

\- Link Requirement

\- Link Form

\- Run Evaluation Schema Test

\- Preview Evaluation Matrix

Design constraints:

\- Evaluation must be generated from the STD, not invented at tender evaluation time.

\- Make pass/fail versus scored criteria visually distinct.
