Screen name:

Clause Detail

User:

STD Administrator, Legal Reviewer, Auditor

Purpose:

Inspect one clause, its legal text, source anchor, parameters, rules, and render behavior.

Primary user goals:

\- Verify locked clause text.

\- See whether clause is configurable or generated.

\- Inspect parameters embedded in the clause.

\- Confirm text hash and source anchor.

\- Review linked validation rules.

Required sections:

1\. Clause identity header.

2\. Legal/source text panel.

3\. Mutability and edit policy panel.

4\. Source traceability panel.

5\. Parameters used by clause.

6\. Rules affecting clause.

7\. Render preview.

8\. Audit history.

Required fields:

\- Clause ID

\- Clause number

\- Clause title

\- Section

\- Mutability type

\- Legal text hash

\- Source page

\- Source anchor

\- Effective text

\- Render block ID

\- Activation blocker status

Required actions:

\- View Source Page

\- View Render Preview

\- Open Parameter

\- Open Rule

\- Flag Legal Review Issue

\- Compare with Previous Version

Design constraints:

\- No free editing of locked text.

\- Any text difference must be shown as a legal/versioning event.
