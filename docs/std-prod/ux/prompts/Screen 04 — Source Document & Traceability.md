Screen name:

Source Document & Traceability

User:

STD Administrator, Legal Reviewer, Auditor

Purpose:

Show official source documents and source anchors used to digitize the STD.

Primary user goals:

\- Verify the source document.

\- Confirm source hash and page/section anchors.

\- Inspect traceability coverage.

\- Find clauses/fields/rules without source anchors.

Required sections:

1\. Source document summary.

2\. Source files table.

3\. Traceability coverage cards.

4\. Anchor map table.

5\. Missing/weak traceability warnings.

6\. Source preview/detail drawer.

Required fields:

\- Source document title

\- Source authority

\- File name

\- File type

\- File hash

\- Upload date

\- Page count

\- Effective date

\- Revision date

\- Verified status

\- Verified by

\- Verification date

Anchor map columns:

\- Engine object type

\- Engine object ID

\- Object title

\- Source section

\- Source page

\- Paragraph/anchor

\- Text hash

\- Confidence

\- Status

\- Actions

Required actions:

\- Upload Source Document

\- Verify Source Hash

\- Open Source Preview

\- View Linked Object

\- Flag Anchor Issue

\- Resolve Missing Anchor

\- Export Traceability Report

Design constraints:

\- Traceability must feel evidentiary, not decorative.

\- Missing source anchors should be treated as activation blockers.
