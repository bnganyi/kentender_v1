Screen name:

Import Package Review

User:

STD Administrator

Purpose:

Review an uploaded STD package before importing it into the engine.

Primary user goals:

\- Upload package.

\- Inspect manifest and checksums.

\- Validate import contents.

\- See what will be created or updated.

\- Import only into safe draft states.

Required sections:

1\. Upload/dropzone.

2\. Package manifest summary.

3\. File list and checksum results.

4\. Import impact summary.

5\. Validation findings.

6\. Import action panel.

Required fields:

\- Package ID

\- Family code

\- Version code

\- Package status

\- File count

\- Checksum status

\- Source document hash

\- Import target state

\- Import mode

\- Validation status

Required actions:

\- Upload Package

\- Run Dry Run

\- View Manifest

\- View File Details

\- Import as Draft

\- Cancel Import

\- Export Dry Run Report

Design constraints:

\- Never allow direct import into Active.

\- Clearly show whether package is activatable or draft-only.
