Screen name:

Audit Log

User:

Auditor, STD Administrator, Compliance Officer

Purpose:

Provide full audit trail for STD administration events.

Primary user goals:

\- Search and filter audit events.

\- Inspect who changed what and when.

\- Verify approvals, imports, activations, supersessions, and render/hash events.

\- Export audit evidence.

Required sections:

1\. Audit search/filter bar.

2\. Audit event table.

3\. Event detail drawer.

4\. Export controls.

Required filters:

\- Date range

\- Actor

\- Object type

\- Object ID

\- Event type

\- Severity

\- Lifecycle state

\- Approval stage

Audit table columns:

\- Timestamp

\- Actor

\- Event type

\- Object type

\- Object ID

\- Previous state

\- New state

\- IP/session reference

\- Hash/reference

\- Actions

Required actions:

\- Open Event

\- View Object

\- Export Audit Log

\- Verify Hash

Design constraints:

\- Must feel evidentiary.

\- Do not make audit logs editable.
