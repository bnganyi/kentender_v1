Screen name:

Form Detail and Field Builder

User:

STD Administrator, Forms Designer

Purpose:

Configure the schema of one form.

Primary user goals:

\- Inspect form purpose and source.

\- Manage fields, sections, validations, and evidence.

\- Preview bidder/procuring entity experience.

\- Confirm activation conditions.

Required sections:

1\. Form identity header.

2\. Form metadata panel.

3\. Field builder table.

4\. Evidence requirements panel.

5\. Activation rules panel.

6\. Preview panel.

7\. Source traceability panel.

Required fields:

\- Form code

\- Form title

\- Respondent type

\- Workflow stage

\- Required/conditional

\- Source section/page

\- Activation rule

\- Render template

\- Submission validation

\- Carry-forward target

Field table columns:

\- Field key

\- Label

\- Data type

\- Required

\- Help text

\- Validation

\- Evidence link

\- Carry-forward target

\- Actions

Required actions:

\- Add Field

\- Reorder Field

\- Add Evidence Requirement

\- Preview Form

\- View Source

\- Run Form Validation

\- Export Form Schema

Design constraints:

\- Active STD forms are read-only.

\- Make downstream carry-forward visible where applicable.
