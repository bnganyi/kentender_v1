Screen name:

Render Blocks

User:

STD Administrator, Document Renderer Designer

Purpose:

Configure how structured STD data renders into tender and contract documents.

Primary user goals:

\- See all renderable document blocks.

\- Confirm source data bindings.

\- Preview generated output.

\- Identify missing templates or broken render bindings.

Required sections:

1\. Render profile summary.

2\. Render block table.

3\. Preview panel.

4\. Data binding panel.

5\. Render validation issues.

Required table columns:

\- Render block ID

\- Document area

\- Section

\- Source data object

\- Template status

\- Required/conditional

\- Output format

\- Last preview status

\- Validation status

\- Actions

Required actions:

\- Open Render Block

\- Preview Output

\- View Data Bindings

\- View Source Section

\- Run Render Test

\- Export Render Profile

Design constraints:

\- Render blocks must be deterministic and auditable.

\- Missing render templates should block activation where required.
