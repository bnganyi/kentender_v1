Screen name:

Usage and Tender Bindings

User:

STD Administrator, Auditor

Purpose:

Show tenders that use or have used a specific STD version.

Primary user goals:

\- See whether version is used in active or historical tenders.

\- Understand deletion/supersession restrictions.

\- Open tender binding records.

\- Audit generated bundle hashes.

Required sections:

1\. Usage summary.

2\. Tender bindings table.

3\. Generated artifact summary.

4\. Supersession/addendum impact panel.

Required table columns:

\- Tender ID

\- Tender title

\- Procuring entity

\- Binding date

\- Tender status

\- Published bundle hash

\- Addendum status

\- Version used

\- Actions

Required actions:

\- Open Binding

\- View Generated Bundle

\- View Addendum Impact

\- Export Usage Report

Design constraints:

\- Make it clear that used STD versions cannot be deleted.

\- Superseded versions remain readable if historically used.
