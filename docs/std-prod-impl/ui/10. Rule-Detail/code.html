String Length Validation - Tender Reference

RULE-VAL-REF-01

Ensures that the tender reference ID adheres to the mandatory Kenyan procurement standard for IT projects, specifically requiring a length between 12 and 32 characters to accommodate regional and agency identifiers.

assert(length(tender_ref_id) >= 12 && length(tender_ref_id) <= 32);

"The Tender Reference ID must be between 12 and 32 characters in length."

Ensures that the tender reference ID adheres to the mandatory Kenyan procurement standard for IT projects, specifically requiring a length between 12 and 32 characters to accommodate regional and agency identifiers.

The user must provide a tender reference ID that matches the IT-specific naming convention (e.g., KE-PPRA-IT-XXXX).
