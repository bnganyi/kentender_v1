## Payment milestones

| Milestone | Percentage |
| --- | --- |
| Contract signing and commencement | 20% |
| Phase 1 go-live and Acceptance Certificate | 30% |
| Phase 1 post-implementation sign-off, three months after Phase 1 go-live | 10% |
| Phase 2 go-live and Acceptance Certificate | 25% |
| Phase 2 post-implementation sign-off | 10% |
| Retention release after twelve-month Phase 2 warranty period | 5% |

## Contract carry-forward decisions

| Topic | Carry-forward behavior |
|---|---|
| Performance security | Becomes contract obligation after award; value is 10% of contract price. |
| Payment milestones | Must be stored as contract payment schedule; percentages total 100%. |
| Warranty | 12 months per phase from date of acceptance. |
| SLA | P1/P2/P3 response and resolution matrix; uptime 99.5% monthly. |
| IP and escrow | Customizations/configurations/bespoke development transfer or escrow; Microsoft core source code excluded. |
| Subcontracting | Requires prior written approval; supplier remains responsible. |
