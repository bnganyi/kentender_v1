# 1. Implementation Mandate

Cursor must implement the derived generated models as binding system contracts.

These models are not optional reports. They are the formal operational interface between the STD Engine and downstream procurement modules.

The implementation must enforce the following principles:

1. Bundle, DSM, DOM, DEM, and DCM are generated from an STD Instance.
2. Generated models are versioned.
3. Published or snapshotted generated models are immutable.
4. Every generated element must preserve source traceability.
5. Submission consumes DSM.
6. Opening consumes DOM.
7. Evaluation consumes DEM.
8. Contract Management consumes DCM.
9. Downstream modules must not create independent rules.
10. BOQ arithmetic correction occurs only in DEM.
11. DOM must not contain evaluation outcomes or arithmetic correction.
12. DCM for Works BOQ must source price from corrected evaluated BOQ total after evaluation/award.
13. Stale models block readiness and legally relevant downstream consumption.
14. Manual downstream rule injection attempts must be denied and audited.

|---|---|
