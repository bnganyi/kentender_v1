# Tender Management v2 — implementation tracker

## Goal

Deliver **Tender Management v2** as an **STD-native orchestration** layer: package-originated tenders, **STD instance + Bundle/DSM/DOM/DEM/DCM + publication snapshot** gates, then clarifications, addenda, sealed bids, closing, and **DOM/DEM/DCM handoffs**—without Tender authoring submission/opening/evaluation/contract rules. **Done** on any row requires **Evidence** (tests/commands/PR paths) per [`.cursor/rules/kentender-tdd-playwright-quality-gate.mdc`](../../../../../.cursor/rules/kentender-tdd-playwright-quality-gate.mdc); Desk/UI rows additionally require **Playwright** (or a logged **blocker**).
