## 8. Phase P5 — UI Implementation Contract

## 8.0 Default UI Visibility Contract

This section is binding. Cursor must not treat it as presentation guidance.

Procurement Planning v2 must be rigorous underneath but calm and understandable on screen. The default view for ordinary users must show business meaning first and technical evidence only after expansion.

### 8.0.1 Default Visibility Order

Every ordinary Planning screen must present information in this order:

```text
1. Business summary
2. Current state in business language
3. Next action
4. Blockers, if any
5. Primary action
6. Secondary actions
7. Evidence link
8. Technical details only after explicit expansion or inside Evidence / Advanced / Audit views
```
