## 0.1 Document Precedence

For Procurement Planning P5 UI work, Cursor must apply this precedence order:

| Rank | Document | Controls |
|---:|---|---|
| 1 | Procurement Planning v2 — P5 UX Reset Implementation Tracker | Execution rows, gate sequence, evidence requirements, review status. |
| 2 | Procurement Planning v2 — P5 UX Reset Implementation Contract | Detailed implementation contract, routes, components, view-models, tests, no-go rules. |
| 3 | Procurement Planning v2 — UX Reset Wireframe Pack | Wireframes, screen layout, copy, selectors, acceptance expectations. |
| 4 | Procurement Planning v2 backend/domain/governance/seed artifacts | Data model, state, permissions, services, seed values, legal controls. |
| 5 | Earlier Procurement Planning v2 UI Specification and older P5 tracker rows | Superseded for UI where they conflict with this reset. |

If an earlier document requires handoff-card stacks, persistent Planning Evidence sidebar, raw lifecycle panels, default technical evidence cards, or Evidence/Advanced tabs in the package workspace, this tracker supersedes that instruction.

---

## 0.2 Superseded P5 Rows and Patterns

The following earlier P5 implementation patterns are superseded as ordinary default UI:

```text
ModuleJourneyContextHeader as a dominant default Planning shell element
Planning handoff card stacks on Planning Home
Planning handoff card stacks on Packages
Planning Workflow Status panels in ordinary package views
Planning Evidence as a persistent ordinary Planning submenu
Planning Inclusion / Release / Consumption cards as primary workbench content
Evidence tab as a default Package Detail tab
Advanced tab as a default Package Detail tab
right-side implementation-stage shell panel
technical details links attached to every card or row
raw lifecycle keys, raw handoff codes, source_object_code/target_object_code labels, JSON labels, audit IDs in ordinary default views
```

Those concepts may still exist behind:

```text
View Evidence
Technical Details
Advanced
Audit View
Cross-module Evidence & Audit
```
