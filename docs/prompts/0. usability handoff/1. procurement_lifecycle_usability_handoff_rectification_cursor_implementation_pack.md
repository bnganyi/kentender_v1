## 1. Purpose of This Cursor Pack

This Cursor Implementation Pack translates the rectification strategy into explicit implementation instructions.

It exists because the completed procurement modules are individually strong but feel disconnected and complex to users. The corrective goal is to make the system feel like one coherent procurement journey while preserving strict legal controls.

Cursor must implement:

1. a cross-module **Procurement Journey** aggregation layer;
2. visible **Procurement Handoff Cards**;
3. a coherent **District Hospital Renovation Works** master seed chain;
4. a **Procurement Home** usability overlay;
5. journey context headers inside existing modules;
6. business-readable readiness summaries, especially for STD/Tender complexity;
7. evidence and audit traceability across modules;
8. usability smoke tests;
9. non-bypass safeguards ensuring the overlay does not become a source of legal truth.

This is not a wholesale rewrite. Cursor must patch the existing modules carefully.
