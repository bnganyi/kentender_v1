## Context

**Why this change.** Procurement Analytics answers four questions across Needs, departmental plans, annual Plan items, Requisitions and Tender proceedings: where does each area stand, what is outstanding and for how long, how long did recorded key steps take, and how much planned value is covered and funded. It is read-only. It assigns no work and records no decision. Home keeps the item-level oversight list; Analytics holds distributions, timing and value.

**What ANL v0.8 requires, in one paragraph.** A server-composed page at `/app/analytics` in `kentender_core` with six peer tabs (Overview, Needs, Departmental planning, Annual planning, Requisitions, Tender proceedings) and routes `/app/analytics` and `/app/analytics/{tab}`. Applied filters `fy`, `dept` and `state` live in the route; search text and the paging cursor never do. Eleven measures (ANL-M-01 to M-11) and five step transitions (T1–T5), each with its own unit and owner source, never added together. Four chart forms (horizontal bar, horizontal segmented bar, vertical grouped bar by month, range strip), each value shown as text, each chart exposing an accessible table. Counts and states keep the current-position rule; time measures use the twelve calendar months ending with the read month. Failure of one region never becomes zero.

**What is not in the request.** No new stored record, DocType, task, decision, permission, forecast, savings figure, utilisation percentage, health or risk score, or overdue claim of Analytics' own. No Contract Management, delivery, inspection, performance or Accounts measure (deferred, ANL §2).

## Key technical decisions

- **D1 Composition by hook.** Core cannot import procurement. New hook `kt_analytics_providers`; each owner supplies `analytics_provider.py` returning facts (instants, Decimal amounts, department attribution, outstanding matters with `since`) under its own scope and the OD-2 aggregate audience. Core computes every band, month bucket, median, percentage and label (ANL §7.1). No SQL over owner tables from core; no DocType; nothing persisted, not even a working-context preference (ANL §16).
- **D2 Neutral reads.** Providers do not call NDS `get_workspace` (persists context) or PLN `get_departmental_plan` (writes); each reads through the owner's scope helper directly. A read creates and marks nothing.
- **D3 Endpoint.** `KC/api/analytics.py::get_procurement_analytics` stays thin; `KC/services/analytics_workspace.py` composes. Inputs: tab, `fy`, `dept`, `state`, search, cursor. Output per region: value or series, unit, owner read time, completeness (complete, incomplete, unavailable) and window bounds. Ten-row pages over a bounded owner revision set with opaque cursors. Count and rows share one scope. The verdict (permitted, no permitted area, filter invalid) returns with the data in one call, so there is no render-then-deny.
- **D4 Failure never becomes zero.** A failed provider makes its measure unavailable. An incomplete one shows the figures it has plus the stated sentence and no percentage. This copies Home's coverage rule and forbids My Work's swallow-and-log.
- **D5 Tender buckets.** One classifier in the Tenders provider maps each Tender once to the §5.2 buckets from `overall_status`, the deadline against the read instant, BOP outcome, EVL case state and AWD stage. "Sent to Contract Management" binds to Award's "Sent to Contracting" stage. A failed read gives "Status unavailable".
- **D6 Coverage basis.** Build ANL-M-07 on Planning's U14 basis (authorised Requisition drawdown by allocation), not the `ProceedingCoverage` table. Reasons: ANL-M-07 says "the same facts PLN shows in U14"; PLN v1.29 §5.4.6 line 606 says "Derive from exact source allocations and quantities included in the authorised Requisition and downstream issued package"; and the A1 fixture (IT peripherals covered 6,500,000 while Tender 041 is unpublished) reconciles only on that basis. Recorded as conflict C1 for PLN to confirm.
- **D7 Page and routes.** Page `analytics`, module Kentender Core, one `desk_page.register`, app-owned `useRouteState()`. Routes `/app/analytics` and `/app/analytics/{tab}`. `fy`, `dept` and `state` are pushed through an own history adapter and validated server-side; search text and cursor stay in component state. Page JSON `roles: []` with an in-page verdict. The menu item stays visible to everyone (ANL §9.1). Never added to `cl_surface_registry` (AGENTS.md §6.5). Changing tab keeps `fy` and `dept` and drops `state`. The first Phase 0 task is a real-browser spike proving query-param push, Back, refresh and shared link.
- **D8 Charts.** Hand-built SVG/CSS Vue components, no library and no `frappe-ui`: horizontal bar (including the from-zero invitation-timing form), horizontal segmented bar with legend, vertical grouped bar by month with twelve slots and "(to date)", range strip with value columns. Every chart exposes a visually hidden table in visual order. No interaction except the stage bar mirroring the stage select. Zero-value segments omitted unless a brief says otherwise.
- **D9 CSS.** A page-scoped copy under `.kt-industry.kt-analytics`, generated by extending `scripts/home_design_css.py` (parameterise class list, scope and source board), with the same computed-style comparison against the board that Home 1A used. Loaded lazily by the page controller only (never app-wide; never a `<style>` block, which esbuild discards). The board's tuned data palette is used because the owner accepted the rendered boards (D-ANL-14: "They a much better fit"); the palette itself stays an open owner approval (FU-ANL-10). Home Phase 1B stays on hold; this plan does not resume it.
- **D10 Time.** Site time; a shared non-negative calendar-day helper is added to core (new, because `home_time._days` is signed and private); clock is `test_clock.current_instant()`; the window is the twelve months ending with the month containing the read time; medians follow ANL §5.4 rule 3 (8.5 for A1 T1).

- **D12 Technical readers.** Administrator, System Manager and Technical Operator read every tab site-wide, read-only, including the funding position (ANL D-ANL-10; KT-STD v1.22 §3A.6). Owner projections must return full facts for them. Sealed bid content and credentials stay excluded. The read entry point is registered with the technical-read conformance gate (KT-STD v1.22 §3A.6 closing paragraph).
