Design acceptance checks
  • The history screen and correction panel are separate artboards; the purchase-editor response is not a substitute.
  • Only Requirement type is selected. Category is visibly derived and cannot be edited independently.
  • The accepted departmental submission, original classification, correction actor/time and reason remain distinct.
  • The affected draft purchase and required recovery are explained before saving, in plain language.
  • Each artboard has one primary task and no internal lifecycle, event or resolver terminology.
