# BUD-CHG-001 v1.9 — Budget & Funding usability correction — implementation plan

## Context

The Project Owner approved the Budget Usability Amendment v0.1 (BUD-UX-001..014) on 13 Sep 2026 and had it consolidated into **BUD-CHG-001 v1.9** (`docs/mvp-1-r1/03_budget/KenTender_BUD-CHG-001_Clean_Budget_and_Funding_v1_9.md`, identical copy under `design/uploads/`). v1.9 supersedes v1.8 and adds 28 usability acceptance criteria (BUD19-AC-001..028) and 14 change rows (BUD19-CHG-001..014). The amendment (`KenTender_BUD_Usability_Amendment_v0_1.html`) is background only; v1.9 is the single authority.

The live app (`kentender_budget`) was proven end to end at v1.6 and its tracker still tracks v1.3. Every screen exists on `kentender_core.desk_page.register` and Industry tokens, and every service the screens need exists (`close_budget` is server-only, never wired). The gap is presentation and journey completeness: internal vocabulary (Current floor, Headroom, Owner scope, Authorised total, Create revision, Register approved budget), an approval screen that leads with identity and a green checklist instead of the money movement, missing pending-work/returned/closed workspace states, no closure UI, reservation rows that don't lead with requisition and source department, no explicit save/submit/unknown-outcome recovery.

**Owner decisions taken during planning (15 Sep 2026):**
- **Spec wins over artboards.** The seven new `.dc.html` boards are ported class-for-class, but where their content contradicts v1.9 §11 (Approval Task board still v1.3-era: Version identity first, Current floor/Headroom, negative shortfall, Funding-impact counts; Budget Detail board shows an 80m December hold), the spec controls. Missing compositions (BUD-DES-01A/01B pending states, 17 Close budget, 06B partial conversion/requires review, Return dialog) get authored as `.dc.html` boards in Phase 0 so every screen has a fidelity oracle before it is built (AGENTS.md §6.6 artboard rule).
- **Scope = BUD19-CHG-001..014 plus only the server reads the screens need.** The v1.8 domain rows never implemented (exact-decimal Money, Funding Reservation requisition/drawdown/source fields, currency-precision provider, token lifetime) are explicit exclusions recorded in the follow-up register, not silently attempted.
- Implementation started 15 Sep 2026 on the owner's instruction to run every phase without stopping.
