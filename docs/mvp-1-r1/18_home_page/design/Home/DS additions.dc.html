Workspace fact card

.kt-fact-card
3actions for youCount unavailableitems you're waiting on2records with outstanding matters

Default · Count unavailable · keyboard focus

Use

  • A supplied count that orients the actor’s own work. Up to four per row, aligned to the grid.
  • Figure 32–34 px, --heading-color, tabular digits. Not indigo: the figure reads as a fact, not a link.
  • Label beneath in --text-muted, verbatim from the change unit.
  • The whole card is the focus target and moves focus to its region. Hover darkens the border only.
  • Incomplete count: Count unavailable replaces the figure.

Don’t

  • No fill, shadow, status bar or chart inside the card.
  • No card for a count the change unit does not supply.

Main column: ordinary · with reason · blocked

Anatomy

  • Line 1: module icon chip, title, then module name and reference as quiet text. Spacing separates them; no delimiter character.
  • Line 2: the action or event, then the timing as quiet text: relative form with the exact time in brackets, always visible.
  • Reason, where present, on its own line with the warning glyph.
  • One action, vertically centred at the right: primary on the region’s first row only.

Variants

  • Main column: indigo glyph (--color-accent-700), button or text link.
  • Rail (.kt-rail-row): neutral glyph, title is the link, one quiet line of state and timing, no button.
  • Your turn, blocked only for blocked work. Ordinary rows carry no Your turn.

Sheet content < 960 px

Grid

  • 12 columns inside the 1200 px sheet, 24 px gutters.
  • Header and fact-card row span 12. Main column 1–8; rail 9–12.
  • Regions are separated by spacing and a 1px rule; none has a fill or border of its own.
  • Main headings 18 px; rail headings 15 px. The rail holds text links only, except a region’s Try again.

Behaviour

  • When the main column is empty after a successful read, a positive line leads it, and an overseen-records region moves from the rail into the main column.
  • Below 960 px of sheet content width (container query), the rail stacks below the main column in the same order and fact cards wrap two per row.
