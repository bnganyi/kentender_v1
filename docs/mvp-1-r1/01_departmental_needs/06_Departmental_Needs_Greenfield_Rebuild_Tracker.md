## Tracker rules

1. Rows are permanent and use `Planned`, `In progress`, `Blocked`, `Done`.
2. `Done` requires the row's own evidence (a command, a test name, a diff) — not "looks right."
3. If a rebuilt file still imports or references a deleted Demand doctype/module, the row that touches it is not Done.
4. No row may introduce a new patch, feature flag, or `*_available()`-style existence gate. If one appears, treat it as a defect in that row, not a valid completion.
