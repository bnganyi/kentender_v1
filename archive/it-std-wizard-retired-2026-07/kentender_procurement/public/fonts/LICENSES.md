# Self-hosted brand fonts

These webfonts are self-hosted (no CDN) and loaded app-wide via
`public/css/kt_fonts.css` (registered in `hooks.py` `app_include_css`).
Only the `latin` + `latin-ext` subsets are shipped for the text families.

| Family | Weights | License | Source |
|---|---|---|---|
| Manrope | 600, 700, 800 | SIL Open Font License 1.1 | Google Fonts |
| Inter | 400, 500, 600, 700 | SIL Open Font License 1.1 | Google Fonts |
| JetBrains Mono | 500, 600 | SIL Open Font License 1.1 | Google Fonts |
| Material Symbols Outlined | variable (100..700) | Apache License 2.0 | Google Fonts |

All four licenses permit redistribution and self-hosting. The woff2 files are
regenerated by `/tmp/fetch_kt_fonts.py` (kept in the task history) from the
Google Fonts CSS2 API latin/latin-ext subsets.
