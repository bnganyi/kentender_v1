# IT Tender Wizard Control Pack v3 — Changelog

## What was fixed

1. Separated application surfaces, configuration steps, and workflow gates.
2. Added a complete screen registry so required screens/views are not omitted.
3. Restored the missing Create Configuration modal as `UI-M01`.
4. Locked the configuration sequence to `CFG-01` through `CFG-09` only.
5. Reclassified Readiness Report, Review Workspace, Tender Document Preview, and Publication Handoff as workflow views, not configuration steps.
6. Renamed `System Inventory` to `System Inventory & Bidder Background`.
7. Replaced `Final Preview` with `Tender Document Preview`.
8. Replaced `Publication Readiness` with `Publication Handoff` for the workflow gate.
9. Added a mandatory screen specification control block to prevent vague or siloed screen specs.

## Still pending

The earlier screen specs must be audited/revised against v3 before continuing to CFG-05.
