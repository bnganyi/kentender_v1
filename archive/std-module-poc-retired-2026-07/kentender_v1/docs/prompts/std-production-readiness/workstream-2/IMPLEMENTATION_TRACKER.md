## Intent (summary)

Convert an **Active STD Template Version** into a **Tender-bound STD Instance** (exactly one current instance per tender), capture tender-specific configuration (parameters, section-bound attachments, Works Requirements, BOQ), generate **versioned** outputs **Bundle / DSM / DOM / DEM / DCM**, take **immutable snapshots** at legally meaningful gates, **lock** after publication, and enforce **downstream consumption by reference only** — not a document portal and not hand-maintained rules in Submission, Opening, Evaluation, or Contract modules.

---

## Rules of engagement

1. **Specs + Cursor pack are law** — Doc 1 defines the model; doc 2 locks ticket scope, non-negotiable rules **STDINST-RULE-001** … **014**, and **implementation order** (doc 2 §24). Do not mark **Done** without evidence for acceptance criteria (or a logged **deviation** in [`ISSUES_LOG.md`](ISSUES_LOG.md)).
2. **Non-negotiable boundaries (doc 1 §3, doc 2 §2.2, §3)** — STD Instance **only** from **Tender** context; no orphan instances; active template only; published state immutable; post-publication change via **addendum** or **supersession**; no manual downstream rule injection; publication requires **Publication Snapshot**.
3. **Out of scope for this pack (doc 2 §2.2)** — Procurement officer Tender UI, supplier/opening/evaluation/contract operational UIs, full Tender lifecycle, PDF engine internals, addendum approval UI (implement hooks/services; UI may follow later).
4. **TDD; evidence-based Done** — Workspace [`.cursor/rules/kentender-tdd-playwright-quality-gate.mdc`](../../../../../.cursor/rules/kentender-tdd-playwright-quality-gate.mdc). Map implementation to **Frappe** (`kentender_procurement` / `tender_management`) rather than assuming the generic `backend/src/modules/std-engine/` tree in doc 2 §4 unless the repo adopts that layout.
5. **Bench / Node** — [`./scripts/bench-with-node.sh`](../../../../../scripts/bench-with-node.sh) for any `bench build` touching desk assets per [`.cursor/rules/frappe-bench-node.mdc`](../../../../../.cursor/rules/frappe-bench-node.mdc).
